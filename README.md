# Aprendizaje Automático

Implementaciones fundamentales de algoritmos de Machine Learning y técnicas de optimización desarrolladas desde cero en Python. Este repositorio contiene código educativo que implementa los fundamentos matemáticos y algorítmicos del aprendizaje automático sin depender de frameworks de alto nivel.

## Descripción

Colección de implementaciones de algoritmos clásicos de inteligencia artificial y aprendizaje automático, incluyendo redes neuronales artificiales, algoritmos evolutivos y sistemas de búsqueda. El objetivo es comprender los fundamentos teóricos mediante implementación directa de los algoritmos.

## Contenido del Repositorio

### Redes Neuronales
- **red_neuronal.py**: Implementación completa de una red neuronal artificial con algoritmo de backpropagation
- **neurona_original.py**: Implementación básica de neurona artificial y perceptrón

### Algoritmos Evolutivos
- **evolution_algorithm.py**: Implementación de algoritmo genético para optimización
- **evolution_original.py**: Versión base del algoritmo evolutivo

### Búsqueda y Grafos
- **busqueda.py**: Algoritmos de búsqueda en grafos (búsqueda en anchura, profundidad, A*, etc.)
- **grafo2.xml**: Archivo de datos con definición de grafo para pruebas

## Características Técnicas

- Implementaciones desde cero sin uso de librerías de ML de alto nivel
- Código educativo enfocado en comprensión de fundamentos
- Algoritmos clásicos de IA y optimización
- Estructuras de datos y representaciones matemáticas explícitas

## Tecnologías

- **Lenguaje**: Python
- **Enfoque**: Implementación manual de algoritmos
- **Paradigma**: Programación orientada a objetos y funcional

## Algoritmos Implementados

### Red Neuronal Artificial
- Perceptrón multicapa
- Función de activación sigmoide
- Algoritmo de retropropagación (backpropagation)
- Descenso de gradiente

### Algoritmo Evolutivo
- Selección natural
- Operadores genéticos (cruce, mutación)
- Función de fitness
- Evolución de poblaciones

### Búsqueda en Grafos
- Búsqueda en amplitud (BFS)
- Búsqueda en profundidad (DFS)
- Algoritmos heurísticos
- Representación de grafos

## Uso

Cada script puede ejecutarse de forma independiente:
```bash
# Ejecutar red neuronal
python red_neuronal.py

# Ejecutar algoritmo evolutivo
python evolution_algorithm.py

# Ejecutar búsqueda en grafos
python busqueda.py
```
## Objetivo Educativo

Este repositorio sirve como referencia para comprender:
- Matemáticas detrás de las redes neuronales
- Principios de algoritmos evolutivos
- Fundamentos de búsqueda y optimización
- Implementación de bajo nivel de conceptos de ML
